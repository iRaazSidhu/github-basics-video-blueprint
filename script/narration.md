## Read-through (continuous narration)

Kabhi socha hai? Code online kaise store hota hai? Ye hai GitHub. Yahan aap projects host karte ho. Files aur changes organize hote hain. Start karo repository se. Project ka home folder. HTML aur CSS files. JavaScript, images, README. Sab ek jagah. Git track karta hai. Har code change history mein record hota hai. Changes select karo. Snapshot ko commit kehte hain. Har commit ek checkpoint. Diff dikhata hai kya badla. Local repo, remote repo. Push: changes GitHub bhejo. Remote par naya update. Pull: latest changes lao. Feature ke liye branch. Alag branch par build karo. Pull request kholo. Review ke baad merge. Ab visibility choose karo. Private: limited access. Public: sab dekh sakte hain. Bas, GitHub basics ye hain. Apna repo create karo!

## Voice direction
Friendly, clear and beginner-friendly. Natural conversational rhythm; don't over-pronounce English terms. Use brief breathing room around “repository”, “commit”, “push”, “pull” and “pull request”.

## Timing note
These timestamps are an edit map, not a requirement to force speech into exactly two seconds per line. Once the voice-over is generated, adjust cuts to the real waveform. Let related visual beats flow continuously where possible.

## Technical accuracy
Git is the version-control system; GitHub hosts repositories and collaboration features. A commit records a snapshot of tracked changes. Push sends local commits to a remote. Pull fetches and integrates remote changes. A pull request proposes changes for review and merge; it is not itself the merge.
