# Narration — GitHub Explained Visually

**Working title:** GitHub Explained Visually  
**Language:** Natural Hinglish (Roman script)  
**Target duration:** ~60 seconds  
**Voice-over:** Generated separately; no audio is included here.

## Script

**[00:00–00:04] Hook**  
Kabhi socha hai ki developers apna code online kaise store karte hain?

**[00:04–00:10] GitHub and repository**  
GitHub ek platform hai jahan aap apna code store, manage aur track kar sakte ho. Sabse pehle, aap ek repository create karte ho. Ise apne project ka digital folder samajh lo.

**[00:10–00:20] Files and Git**  
Is folder mein aap HTML, CSS, JavaScript, images aur doosri project files rakh sakte ho. Ab aata hai Git. Ye aapke project mein hone wale changes ka record maintain karta hai.

**[00:20–00:34] Commits and history**  
Jab aap apne changes save karte ho, Git mein ek snapshot ko commit kehte hain. Har commit aapko samajhne mein help karta hai ki code mein kya change hua tha.

**[00:34–00:42] Push and pull**  
GitHub par code upload karne ke liye aap push use kar sakte ho. Aur GitHub se remote changes apne computer par lane aur integrate karne ke liye pull use kar sakte ho.

**[00:42–00:50] Branches and pull requests**  
Alag feature par kaam kar rahe ho? Branch bana sakte ho. Changes review karne aur merge karne ke liye pull request use hoti hai.

**[00:50–01:00] Visibility and close**  
Aap apne projects ko private ya public rakh sakte ho. Bas, GitHub ke basics samajhne ke liye itna kaafi hai. Ab aap apna pehla repository create kar sakte ho!

## Voice direction
Friendly, confident, beginner-friendly. Natural conversational pace. Avoid sounding like a formal tutorial or over-pronouncing English terms. Pause slightly after “repository”, “commit”, “push”, “pull”, and “pull request”.
