## How to reuse them

- Use the SVG itself as a clean still image, or import it into a design/video editor that supports SVG.
- Duplicate a master for multiple scene beats and change only the crop, zoom, position, highlight, overlay label or animation.
- Keep labels separate from artwork during editing where possible, so wording can be corrected without rebuilding the visual.
- Export WebP/PNG copies only when a target editor requires raster images.
- Keep master artwork in this folder; put optional production exports in a separate folder only when needed.
- No video or voice-over is stored in this repository.
